# Example Contribution

This is a demo file to show the fork → PR workflow.

## Workflow
1. Sync fork with upstream (`tzevk/accent`)
2. Create feature branch `hermes/example-contribution` from `main`
3. Make changes, test locally (`pnpm install`, `pnpm build`)
4. Push to **your fork** `Harshitttttttt/accent`
5. Open PR to upstream `tzevk/accent:main`
